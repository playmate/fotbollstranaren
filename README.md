# Fotbollstränaren

En första prototyp för ett lag med spelare födda 2018.

## Starta
Öppna `index.html` direkt i webbläsaren.

För bästa resultat kan du även köra en enkel lokal webbserver:

### macOS / Linux
```bash
cd fotbollstranaren
python3 -m http.server 8000
```

Öppna sedan:
http://localhost:8000

## Funktioner i denna version
- Matchflik med grafisk fotbollsplan
- 5 egna spelare på plan (4 utespelare + målvakt)
- Bänk med övriga spelare
- Klicka bänkspelare för att sätta in dem
- Dra spelare på planen
- Dra egna spelare från planen till bänken
- Lägg till motståndare, boll, konor och tränare
- Träningsflik med Passningar och Skott
- Färdiga övningar
- Alla objekt i träningsövningarna går att flytta
- Spelarflik
